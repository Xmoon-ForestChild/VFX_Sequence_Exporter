# flipbook_maker
# 🎨 Unity Flipbook Maker (Web Version)

这是一个纯前端的轻量级、开箱即用的 Web 工具，专门为 Unity Shader Graph 开发者和特效美术（VFX Artist）设计。它可以将**序列帧图片**或**单段视频**快速打包、裁切并抠像，生成完美的 Flipbook 纹理图集（Texture Atlas）。

所有处理均在**本地浏览器**中通过 HTML5 Canvas 完成，无需上传服务器，处理速度极快且完全保护您的素材隐私。

## ✨ 核心特性 (Features)

*   **🎬 多格式支持**：支持多选序列帧（PNG, JPG）或直接导入单段视频（MP4, WebM），系统会自动根据网格数量在视频时长内均匀抽帧。
*   **✂️ 自由与 1:1 可视化裁切**：
    *   支持拖拽边缘自由拉伸（矩形裁切）或锁定 1:1 比例裁切。
    *   智能居中算法：即使裁切了长条形矩形，导出图集时也会自动等比缩放并居中到正方形网格中，绝不变形。
*   **🔄 无损画面旋转**：支持自定义输入角度旋转素材，底层采用自适应边界框算法，旋转绝不裁切画面原有的边角。
*   **⏱️ 视频时间轴预览**：提供视频播放控制和进度滑块。您可以一边播放预览动态特效，一边调整裁切框和遮罩位置。可精准设置视频的开始与结束抽帧时间。
*   **🪄 强大的 Alpha 遮罩系统 (Masking)**：
    *   **一键去黑底**：利用亮度转 Alpha 算法，完美抠除黑色背景，生成发光半透明通道。
    *   **边缘羽化遮罩**：内置圆形/方形遮罩，支持自定义羽化（模糊）参数，完美消除特效素材的硬边缘。
    *   **自定义遮罩**：支持上传自定义的透明 PNG 或黑白 JPG 作为遮罩。
    *   **手动涂抹**：内置画笔/橡皮擦工具，可直接在画面上涂抹，手动保留或擦除特定区域。
    *   **红色叠加预览**：开启类似 Photoshop 的快速蒙版预览，精准查看将被抠除的区域。
*   **📦 智能网格计算**：只需输入列数、行数和图集总宽度，系统自动计算每个网格的精确像素尺寸。
*   **📄 导出 Unity 元数据**：一键下载生成的 `.png` 图集，并配套生成 `_meta.json` 文件，内含直接填入 Unity Shader Graph 的完整参数（行列数、帧数等）。

## 🚀 快速开始 (Quick Start)

由于本项目是纯静态的单文件网页应用，**无需任何环境配置或安装 node_modules**。

1.  克隆或下载本仓库到本地。
2.  双击打开 `flipbook_maker.html` 文件（推荐使用 Chrome, Edge 或 Firefox 浏览器）。
3.  开始制作你的图集！

## 🛠️ 使用流程指南 (Workflow)

1.  **设置网格**：在顶部表单输入你需要的列数（Columns）、行数（Rows）和期望的图集总宽度（如 2048）。
2.  **导入素材**：点击选择文件，上传多张序列帧或单个 MP4 视频。
3.  **调整范围与角度**（可选）：
    *   在画面上拖拽蓝色控制手柄调整裁切大小。
    *   输入旋转角度以修正特效方向。
    *   如果是视频，可以拖动时间轴寻找最佳的开始和结束时间。
4.  **处理遮罩与抠图**（可选）：
    *   勾选“抠除黑底”提取半透明通道。
    *   选择“圆形遮罩”并调整“边缘羽化”，柔和特效的边缘。
    *   如有需要，选择“手动涂抹”对局部进行修饰。
5.  **生成与导出**：点击底部蓝色“生成图集”按钮。完成后点击下载 PNG 和配套的 JSON 元数据。

## 🎮 导入 Unity Shader Graph

生成的文件非常适合配合 Unity Shader Graph 中的 `Flipbook` 节点使用：
1. 将下载的 `flipbook_atlas.png` 拖入 Unity 项目。
2. （可选）在贴图设置中勾选 `Alpha Is Transparency`。
3. 在 Shader Graph 中创建一个 `Sample Texture 2D` 节点和一个 `Flipbook` 节点。
4. 将 JSON 文件中的 `Columns` 和 `Rows` 填入 Flipbook 节点的 `Width` 和 `Height` 参数中。

## 💻 技术栈

*   HTML5 & 原生 JavaScript
*   Canvas API (用于所有图像处理、裁剪、混合与缩放)
*   [Tailwind CSS](https://tailwindcss.com/) (通过 CDN 引入，用于快速构建现代 UI)
