
# 🎨 VFX_Sequence_Exporter

一个专为游戏特效美术（VFX Artist）设计的纯前端本地工具。无需安装，双击即可将**视频**或**序列帧**快速转换为去黑底的**透明图集 (Flipbook)** 或 **高清独立序列帧包 (ZIP)**。

## ✨ 核心亮点

*   **⚡ 开箱即用**：纯单个 HTML 文件，全本地浏览器计算，绝不上传数据，保护素材隐私。
*   **🪄 智能去黑底**：自动提取特效明度生成 Alpha 透明通道，完美保留发光质感。
*   **✂️ 无损旋转与裁切**：支持任意角度旋转（边界自适应扩展），支持自由矩形/正方形可视化裁切，导出图集时自动居中防变形。
*   **🖌️ 高级蒙版抠图**：内置边缘羽化、画笔/橡皮擦手动涂抹，并支持导入自定义遮罩图。
*   **📦 双模式导出**：
    *   **高清 ZIP**：按照原始裁切分辨率和自定义帧率提取完整独立序列帧。
    *   **图集 PNG**：自动拼贴为适合 Unity/UE 材质的网格大图，并附带参数 JSON 元数据。

## 🚀 快速开始

1. **获取工具**：直接下载本项目中的 `flipbook_maker.html` 文件。
2. **运行工具**：双击使用主流浏览器（推荐 Chrome / Edge）打开。
3. **工作流四步曲**：
   - **Step 1 导入**：上传 MP4 视频或多张特效图片，可在此处调整底层旋转。
   - **Step 2 裁切**：框选需要保留的画面区域，配置羽化蒙版或手动涂抹多余边缘。
   - **Step 3 预览**：播放视频时间轴，截取需要的特效时间段，实时查看蒙版效果。
   - **Step 4 导出**：设置需要的行列数，一键下载 ZIP 或生成 Flipbook 图集！

## 💡 适用引擎
生成的素材可直接无缝接入 Unity (Shader Graph 的 Flipbook 节点) 或 Unreal Engine (Flipbook 材质函数/Niagara)。
